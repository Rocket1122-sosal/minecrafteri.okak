# Minecrafteri

Статический сайт без сборки и серверной части: `index.html`, `styles.css`, `script.js`.

## Просмотр на компьютере

Открой `index.html` в браузере. Для проверки загрузки нужен HTTP-сервер; в VS Code можно нажать правой кнопкой по файлу и выбрать **Open with Live Server**.

## Добавить сборку RV3

1. Создай папку `downloads`, если её ещё нет.
2. Скопируй архив модов сюда: `downloads/mods.rar`.
3. Обнови сайт. Кнопка RV3 ведёт напрямую на этот архив.

Если архив крупнее 25 MiB, не клади его в статическую сборку Cloudflare Pages: размести архив в GitHub Release и поменяй `href` в `index.html` на URL файла релиза.

## Бесплатная публикация

Для небольшого сайта подойдёт Cloudflare Pages с подключением GitHub: один раз импортировать репозиторий, указать корень проекта как каталог сайта, затем каждый `git push` автоматически публикует обновление. Можно начать с бесплатного адреса `*.pages.dev`. У Cloudflare Pages на бесплатном плане ограничение размера одного файла сайта — 25 MiB, поэтому ZIP большой сборки удобнее выдавать как отдельный файл GitHub Release.

Discord-сервер закрытый, поэтому приглашение на сайт не добавляем. Скопируй `mods.rar` из папки Minecraft в `D:\Projects\Rocketvanilla\web\downloads\mods.rar`. Затем можно подключить репозиторий к GitHub и опубликовать сайт.
